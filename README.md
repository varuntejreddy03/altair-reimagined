# Altair Technologies Inc.

Altair Technologies Inc. multi-page website featuring modern architecture, technology consulting, software development, AI solutions, and training initiatives.

## Features

- **Services**: Software Development, Artificial Intelligence, Cybersecurity, Data Science & Engineering, Full-Stack Development, IT Staffing, Technology Consulting.
- **Skills Lab & Training**: Hands-on technical programs and innovation modules.
- **Industries**: Custom solutions for Healthcare, Financial Services, Retail, Logistics, and Enterprise sectors.
- **Fast, Accessible UI**: Responsive design with semantic typography, dark navy technology accents, and accessible components.

## Development

Run locally with Node.js:

```sh
npm install
npm run dev
```

## Production Build

```sh
npm run build
npm start
```
