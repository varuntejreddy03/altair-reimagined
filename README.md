# Altair Technologies Inc. - Modern Enterprise Web Platform

Official revamped website for **Altair Technologies Inc.** ([altairtechnologiesinc.com](https://www.altairtechnologiesinc.com/)), crafted with an updated enterprise brand identity, modern typography, responsive layout system, and rich interactive features.

## 🚀 Features

- **16 Fully-Authored Pages**: Complete fidelity to authentic company content covering About Us, Services (AI & Emerging Tech, Cybersecurity, Data Science & Analytics, Full Stack Development, IT Staffing & Consulting, Training & Innovation), Case Studies, Projects, Careers, and Contact.
- **Brand Identity & Color Palette**:
  - Cobalt Blue (`#1E40AF`)
  - Electric Cyan (`#0284C7`)
  - Deep Midnight Navy (`#0A1128`)
  - Clean Paper White (`#FFFFFF`)
- **Responsive Architecture**: Fully optimized for desktop, tablet, and mobile (tested across 320px to 480px viewports with zero horizontal overflow).
- **Interactive Navigation**: Mega menu dropdown for services with animated vector chevrons, accessible mobile drawer, and sticky navigation.
- **Fast Performance**: Instant client-side routing, high-resolution optimized SVG/WebP assets, and fast Vite bundling (< 1s build time).

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailored CSS with design tokens, modern grid/flex layouts, and fluid clamp typography
- **Icons & Assets**: Custom SVG vector components and crisp brand assets
- **Deployment Ready**: Standard SPA static build output (`dist/`)

## 📦 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or pnpm

### Installation

```bash
git clone https://github.com/varuntejreddy03/altairtechnologiesinc.git
cd altairtechnologiesinc
npm install
```

### Development Server

```bash
npm run dev
```

Visit `http://localhost:5173` to preview the site locally.

### Production Build

```bash
npm run build
npm run preview
```
